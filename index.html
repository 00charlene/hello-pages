單筆新增

只填「單字」也可以，按「AI 幫我補齊」讓 Claude 補上音標、詞性、釋義和例句。

批次貼上

一行一個單字。可以只貼單字，也可以用 單字 = 意思 的格式自己寫意思。

從照片抓單字

上傳課本、講義或路標的照片。可以讓 AI 掃描整張圖，也可以自己在圖上 拖曳框選不會的字，只問框裡面的內容。

還沒有照片。

支援 JPG / PNG / GIF / WebP，單張上限 10 MB。

在圖片上按住並拖曳，就能框出一個區域；框好後按下方按鈕送給 AI。

辨識結果

勾掉不想要的，剩下的按「加入單字庫」。文字可以直接點進去修改。

開始複習

採用間隔複習：答對的字下次會晚一點再出現，答錯的字很快就會再遇到。

Claude API 設定

照片辨識和 AI 補齊會直接從你的瀏覽器呼叫 Claude API，所以需要你自己的 API key。 到 Claude Console 建立一組，貼進來即可。

安全提醒：key 會存在這台裝置的瀏覽器 localStorage 裡， 任何能操作這個瀏覽器的人、或這個頁面上的任何腳本都讀得到。 請用一組專門給這個網站的 key、在 Console 設好用量上限，不要用公司或正式產品的 key。

資料存在哪裡

所有單字都存在這個瀏覽器的 localStorage，不會上傳到任何伺服器（只有你送去辨識的照片會傳給 Claude API）。 換裝置或清瀏覽器資料前，記得先到「我的單字」把 JSON 匯出來。
